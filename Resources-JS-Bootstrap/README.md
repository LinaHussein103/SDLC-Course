# Beginner Resources: JavaScript and Bootstrap

A short list of the best places to start. Use one or two, not all of them.

## JavaScript Basics

### Start here

- [W3Schools JavaScript Tutorial](https://www.w3schools.com/js/): Short lessons with a "Try it Yourself" editor, so you can run code right away. Best for your first week.
- [freeCodeCamp: Learn to Code](https://www.freecodecamp.org/learn): Free interactive lessons you do in the browser, with exercises that check your answers.

### Go deeper

- [The Modern JavaScript Tutorial (javascript.info)](https://javascript.info): A full step-by-step course with clear examples. Use it after the basics, when you want to understand why things work.

### Keep open as a reference

- [MDN: Learn JavaScript basics](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Scripting): Accurate lessons from Mozilla. Great when you ask "what does this do?"

## Bootstrap

- [Bootstrap Documentation](https://getbootstrap.com/docs/): The official docs. Start with the "Get started" page to add Bootstrap to your page, then copy and edit the examples for the grid, buttons, navbar, and cards.
- [W3Schools Bootstrap 5 Tutorial](https://www.w3schools.com/bootstrap5/): A gentle introduction with small examples you can edit and run in the browser.

## Video Channels on YouTube

Search for the topic name on these channels:

- **Traversy Media**: popular Bootstrap crash courses
- **freeCodeCamp.org**: long, beginner-friendly JavaScript courses
- **Programming with Mosh**: clear JavaScript basics

**Tip:** Bootstrap 5 is the current version. Choose a recent video, because older ones may teach Bootstrap 3 or 4, which look a bit different.

## Suggested Learning Order

1. Learn the JavaScript basics: variables, functions, `if` statements, loops, and click events.
2. Build a small project, like the Click Counter.
3. Learn Bootstrap's grid and card classes.
4. Build the Bootstrap Profile Cards project.
5. Keep MDN and the Bootstrap docs open whenever you get stuck.

## Study Tips

- Type the code yourself instead of copying and pasting, even when it feels slow.
- Change one thing at a time and refresh the browser to see what happens.
- When you get an error, open the browser Console (press **F12**) and read the message.
- Build small things often. Twenty minutes a day beats one long session a week.
