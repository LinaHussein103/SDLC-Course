# 🚀 Industry Practices Using the SDLC

### A Codeflow PSUT Course

**Learn. Build. Compete. 💜**

Welcome to the official repository for **Industry Practices Using the SDLC**, a hands-on course organized by Codeflow PSUT at Princess Sumaya University for Technology.

## 💻 About the Course

This course bridges the gap between academic programming knowledge and real-world software engineering.

Rather than focusing solely on learning programming languages, we'll explore how professional development teams plan, design, build, test, collaborate, and deliver software.

Students will apply these concepts through practical exercises, mini projects, and a collaborative final project.

## 📚 What You'll Learn

- Software Development Life Cycle (SDLC)
- HTML, CSS, and JavaScript fundamentals
- Git, GitHub, and version control
- Requirements gathering and software design
- APIs and databases
- Testing, debugging, and code reviews
- Agile workflows and team collaboration
- AI-assisted software development
