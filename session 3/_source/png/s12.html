What is a user flow?

A diagram of the steps and decisions a user goes through to complete one goal. It helps teams spot missing screens, dead ends and unnecessary steps — before anything is drawn in detail.

User flow

What the user does, step by step, toward a goal. Screens + decisions.

Database schema

How data is stored: tables, keys and relationships. No user steps.

Architecture diagram

How system components connect: app, API, database, services.
