What is UI?

User Interface — everything a person sees, hears and touches to operate a product: the visible layer between the user and the system.

1
Visual elements — icons, images, cards, colour blocks
2
Buttons, forms & navigation — the controls people operate
3
Typography & colour — font, size, weight, palette, contrast
4
Layout & visual hierarchy — what the eye sees first, second, third
5
Interactive elements — toggles, tabs, states (pressed, disabled, loading)

Think of UI as the “what”: the screen-level decisions you could point at in a screenshot.
